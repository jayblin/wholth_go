# Оптимизировать скрипт htmz

Сейчас в main.js скрипт, который отображает контент, приходящий в htmz-iframe
работает в нексольких режимах:
1. Если в пришедшем документе есть элемент `<h1>`, то все элементы этого
   документа, имеющие атрибут id, заменят собой элементы с тем же id в top
   документе;
2. Если в url, ответ которого записался в iframe, есть указание на фрагмент
   (напр. /ulr#fragment - фрагмент тут это #fragment), и, если в top-документе
   есть элемент id, которого равен этому фрагменту, то этот элемент будет
   переписан содержимым iframe'а.
3. Обработка типа документа text/plain - любой такой текст отображается как
   нотифайка.

Нужно сделать так, чтобы работал только первый вариант. Для этого потребуется
поменять некоторые go-шаблоны и ответы некоторых роутов.

Для начала можно из всех экшенов форм где используется схема с фрагментов,
нужно удалить фрагмент. Затем пройтись по сайту и проверить, что сломалось и
пофиксить.
