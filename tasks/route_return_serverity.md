# Пусть роуты возвращают (error, severity)

Сейчас роуты, которые лежат в `routes`, это стандартные хэндлеры http-запросов.
Нужно сделать так, чтобы они возвращали `(error, logger.Severity)`, и в
`main.go` по завершению работы роута, возвращаемый им error должен логироваться
на основе severity.
Это нужно чтобы не делать `container.Log(...)` в каждом роуте.
